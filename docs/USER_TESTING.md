## Method

- Participants receive only the live link, no instructions.
- Tasks: (1) check the sample caption and fix it, (2) send it for review, (3) as reviewer, approve it, (4) find who approved and why.
- Measured per task: time, completion, errors. Afterwards: three 1–5 ratings (ease, trust in findings, would use) and quotes.
- Every issue is logged as a GitHub issue labelled `user-test`; the top 5 are fixed before code freeze.
